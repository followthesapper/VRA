We validate VRA through baseline experiments on $N=1009$ and cross-modulus robustness testing across $N \in \{997, 1009, 1013, 2017\}$.

\textbf{Note on Implementation:} During validation, we discovered and corrected a critical implementation bug in coherent averaging. The original implementation incorrectly averaged power spectra (incoherent averaging: $\sum |U_m|^2/M$) instead of summing complex FFTs before squaring (coherent averaging: $|\sum U_m/M|^2$). All results presented here use the corrected coherent implementation, which properly preserves phase relationships and enables $\sqrt{M}$ scaling.

\subsection{Metrics Collected}

\begin{enumerate}

    \item Base variance (CV) across random base subsets
    \item Peak detection: TP, FP, FN counts
\end{enumerate}

\subsection{Cross-Modulus Robustness Validation}

To validate that VRA regime boundaries generalize beyond $N=1009$, we conducted a comprehensive sweep across four prime moduli: $N \in \{997, 1009, 1013, 2017\}$.

\subsubsection{Test Design}

For each modulus, we tested 6-7 regime points spanning $\rho \in [0.01, 0.50]$:
\begin{itemize}
    \item Find order $r$ closest to target $\rho$ for each $N$
    \item Generate random same-order bases (or phase-aligned for HIGH SNR)
    \item Run $M$ sweep: $M \in \{1,4,8,16,32\}$
    \item Compute $\sqrt{M}$ fit with bootstrap confidence intervals (100 resamples)
    \item Measure precision/recall at validated radius $R$
\end{itemize}

\textbf{Total data points:} 19 regime points across 4 moduli (some moduli lacked sufficient bases for all target $\rho$ values).

\subsubsection{Regime Boundary Validation}

The original $N=1009$ regime boundaries ($\rho_1 = 0.146$, $\rho_2 = 0.263$) are consistent with cross-modulus data:
\begin{itemize}
    \item \textbf{HIGH/TRANSITION transition:} Observed at $\rho \approx 0.08-0.17$ across moduli
    \item \textbf{TRANSITION/LOW transition:} Observed at $\rho \approx 0.25-0.26$ across moduli
    \item \textbf{Variance:} Boundary uncertainty estimated at $\pm 0.05$ in $\rho$
\end{itemize}

\textbf{Conclusion:} The three-regime structure is robust across moduli. While exact boundaries may vary by $\pm 5\%$ in $\rho$, the qualitative regime behavior (phase alignment requirement, $\sqrt{M}$ scaling quality, precision) generalizes reliably.
