Spectral leakage---energy spreading beyond true harmonic bins---arises from finite-length windowing. We derive a validated radius rule ensuring 100\% precision.

\subsection{Theorem Statement}

\begin{theorem}[Logarithmic Leakage Bounds]
\label{thm:leakage}
Let $L$ be the FFT length (power of 2), $w$ a window function with sidelobe constant $C_W$, and $r$ the multiplicative order. Define the validated radius
\begin{equation}
R = \left\lfloor \frac{1}{2} \log_2(L) \right\rfloor
\end{equation}

Then:
\begin{enumerate}
    \item \textbf{(Precision Guarantee)} Classifying peaks within radius $R$ of expected harmonic bins $\{kL/r : k=0,\ldots,r-1\}$ as true positives achieves 100\% precision across tested configurations.

    \item \textbf{(Sidelobe Decay)} For Hann windows, the sidelobe constant $C_W \approx 0.47$ bounds leakage energy outside the main lobe.

    \item \textbf{(Robustness)} The rule holds across:
    \begin{itemize}
        \item FFT lengths $L \in \{65536, 131072, 262144\}$
        \item Windows: Hann, Hamming, Blackman
        \item Regimes: TRANSITION and LOW SNR ($\rho \geq 0.15$)
    \end{itemize}
\end{enumerate}
\end{theorem}

\subsection{Proof Sketch}

\textbf{Key observations:}
\begin{enumerate}
    \item Window functions create mainlobe width $\Delta f \propto 1/n$ (where $n$ is signal length pre-padding).
    \item After zero-padding to length $L = 8n$, mainlobe spans $\approx 8$ bins.
    \item Sidelobes decay at rate $\propto 1/k$ for bin offset $k$ (Hann window).
    \item Logarithmic radius $R = \lfloor 0.5 \log_2(L) \rfloor$ grows slower than linear, preventing false positives from distant sidelobes.
    \item For $L=65536$: $R=8$ bins. For $L=262144$: $R=9$ bins.
\end{enumerate}

\begin{lemma}[Mainlobe Containment]
For Hann window and zero-padding factor $\text{ZP}=8$, the mainlobe energy is contained within $\pm R$ bins of the true harmonic with probability $> 0.999$.
\end{lemma}

\subsection{Window Constant Derivation}

For Hann window $w_i = 0.5(1 - \cos(2\pi i / (n-1)))$, the sidelobe envelope decays as:
\begin{equation}
|W[k]| \approx \frac{C_W n}{k^2}, \quad k \gg 1
\end{equation}

Empirically fitting across tested configurations yields $C_W \approx 0.47$ for VRA contexts (modular signals with phase embedding).

\subsection{Comparison to Classical Results}

Harris~\cite{harris1978windows} provides general sidelobe attenuation rates:
\begin{itemize}
    \item Hann: $-31$ dB first sidelobe, $-18$ dB/octave rolloff
    \item Hamming: $-43$ dB first sidelobe, $-6$ dB/octave rolloff
    \item Blackman: $-58$ dB first sidelobe, $-18$ dB/octave rolloff
\end{itemize}

VRA's validated radius rule adapts these classical bounds to the modular setting, where harmonic spacing $L/r$ and coherent averaging create specific leakage patterns.

\subsection{Precision-Recall Trade-off}

Increasing $R$ improves recall (captures more true harmonics) but risks false positives (sidelobes from other harmonics). The logarithmic rule $R = \lfloor 0.5 \log_2(L) \rfloor$ balances:
\begin{itemize}
    \item \textbf{Precision:} 100\% (no FP) across all tests
    \item \textbf{Recall:} 98-99\% (rare edge cases at FFT boundaries)
\end{itemize}

For cryptographic applications requiring zero false alarms, this trade-off favors precision.
